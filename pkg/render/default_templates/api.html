API Reference

Base URL

{{.BaseURL}}/api/v1

GET /schemas

Returns a JWS compact serialization containing all registered attestation schemas.

curl {{.BaseURL}}/api/v1/schemas.jwt

The payload contains a data array of SchemaMeta objects.

GET /schemas/{schemaId}

Returns a JWS compact serialization containing a single SchemaMeta object.

curl {{.BaseURL}}/api/v1/schemas/{uuid}.jwt

GET /orgs (SIROS extension — not part of TS11)

Returns an index of the organizations contributing to this registry, each with a link to its organization-scoped schema list.

curl {{.BaseURL}}/api/v1/orgs.json

GET /orgs/{org}/schemas (SIROS extension — not part of TS11)

Returns the same paginated list shape as GET /schemas, filtered to TS11-compliant schemas contributed by one organization. Every schema object is identical to the one served from the global list — filtering happens by which resource you request, not by a new field on SchemaMeta, so nothing here affects TS11 conformance.

curl {{.BaseURL}}/api/v1/orgs/{org}/schemas.json

To query a set of organizations, fetch each one's list and merge client-side — there is no static resource for an arbitrary combination.

Signature Verification

Public keys are published as a JWKS at {{.BaseURL}}/api/v1/.well-known/jwks.json.
